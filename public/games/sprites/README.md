# 游戏页像素素材

把站长备份里的宝可梦 / 像素图放到这里，然后在 `data/games-page.json` 里引用路径，例如：

```json
"spriteDeck": [
  "/games/sprites/your-pikachu.png",
  "/games/sprites/your-bulbasaur.png"
],
"cover": "/games/sprites/your-cover.png"
```

当前仓库自带的 `pixel-mon-*.svg` / `pixel-ball.svg` 仅为**自制示意图**，非官方美术。

建议：PNG/GIF，尺寸 64–256px，透明底。
